### 演講題目： 具冒充者與欺騙攻擊偵測之語者辨識  
 
## 二、演講內容摘要

這次演講主要是在介紹語者辨識系統，以及這類系統在面對冒充者與欺騙攻擊時，應該如何進行防禦與偵測。語者辨識簡單來說，就是透過一個人的聲音特徵來判斷說話者的身分。這種技術可以應用在門禁系統、語音登入、金融身分驗證、智慧助理等情境。

不過語者辨識系統並不是完全安全的，因為攻擊者可以用不同方式偽裝成目標語者，例如模仿聲音、播放錄音、使用語音合成或語音轉換技術。這些攻擊可能讓系統誤以為攻擊者就是合法使用者，所以需要設計反欺騙攻擊的偵測方法。

演講中介紹了語者辨識的基本類型，包含語者驗證與語者識別，也說明了 text-dependent 和 text-independent 的差異。後面也介紹了常見的語音特徵擷取方法，例如 CQCC、i-vector、Total Variability，以及使用 Ensemble Learning 整合多個分類器來提高系統判斷能力。


## 三、語者辨識的基本概念

### 1. 什麼是語者辨識？

語者辨識是透過說話者的語音來辨別身分。也就是說，系統不是看文字內容，而是分析聲音本身的特徵。

例如同一句話，不同人講出來會有不同的音色、頻率、語調、發音習慣，因此系統可以從這些特徵中判斷說話者是誰。

我自己的理解是，語者辨識有點像「用聲音當作指紋」。每個人的聲音雖然可能會受到情緒、環境、麥克風影響，但整體仍然會有一些個人特徵可以被模型學習。

### 2. 語者辨識的類型

#### 語者驗證 Speaker Verification

語者驗證是判斷「這個人是不是他聲稱的那個人」。

例如使用者說自己是 A，系統就會比對他的聲音和 A 的聲音模型是否相似。如果相似度夠高，就通過驗證；如果不夠高，就拒絕。

#### 語者識別 Speaker Identification

語者識別是判斷「這段聲音是誰說的」。

也就是系統會從多個已知語者中找出最可能的說話者。這比較像分類問題，系統要從很多候選人裡面選出一個最符合的身分。


## 四、語者辨識系統中的攻擊問題

### 1. 冒充者與目標語者

投影片中有提到三種角色：

- 冒充者 Imposter
- 目標語者 Target
- 欺騙攻擊 Spoofing attacks

冒充者就是想要假裝成合法使用者的人。目標語者則是被模仿或被攻擊的合法使用者。

### 2. 常見欺騙攻擊類型

#### 人聲模仿 Impersonation

攻擊者直接模仿目標語者的聲音。這種方式比較依賴攻擊者本身的模仿能力。

#### 錄音回放 Replay

攻擊者取得目標語者的錄音後，在驗證時直接播放錄音。這是很常見也很實際的攻擊方式，因為錄音設備很容易取得。

#### 語音合成 Speech Synthesis

攻擊者使用語音合成技術產生類似目標語者的聲音。現在 AI 語音合成越來越進步，所以這類攻擊也越來越需要注意。

#### 語音轉換 Voice Conversion

攻擊者把自己的聲音轉換成目標語者的聲音。這種方式不是單純播放錄音，而是利用模型改變聲音特徵。


## 五、Physical Access 與 Logical Access

### 1. Physical Access

Physical Access 可以理解成攻擊者透過實體環境接近系統，例如拿喇叭播放錄音給麥克風收音。

這類攻擊常見例子是錄音回放。因為系統實際收到的是聲音訊號，但這個聲音可能不是本人現場說的，而是被播放出來的錄音。

### 2. Logical Access

Logical Access 則是攻擊者直接透過系統或資料流程進行攻擊。

例如使用語音合成或語音轉換產生假的語音，再送進辨識系統。這類攻擊通常和軟體、模型或資料處理流程比較有關。



## 六、Text-dependent 與 Text-independent

### 1. Text-dependent

Text-dependent 是指語音內容固定或有限制。例如系統要求使用者說出特定密碼或指定句子。

這種方法比較容易訓練，辨識效果通常也比較好，因為系統知道使用者應該說什麼內容。

### 2. Text-independent

Text-independent 是指不管說話內容是什麼，都要能判斷說話者身分。

這種方法比較彈性，但也比較困難，因為系統不能依賴固定語句，只能從聲音特徵本身判斷說話者。



## 七、語音特徵擷取方法

### 1. 常數 Q 轉換 CQT

CQT 最早應用在音樂處理領域，它產生的頻譜特色是：

- 頻率軸不是線性尺度，而是對數尺度
- 頻率改變時，窗口長度也會跟著改變

這和一般 FFT 不太一樣。FFT 的頻率解析方式比較固定，而 CQT 更接近人耳對聲音頻率的感受方式。

### 2. CQCC 語音特徵

CQCC 是結合 CQT 的語音特徵擷取方法。它會先對語音訊號做前處理，接著進行常數 Q 轉換，再取對數、均勻採樣，最後透過離散餘弦轉換得到特徵。

大致流程可以整理成：

1. 輸入語音訊號
2. 前處理
3. 常數 Q 轉換
4. 取對數
5. 均勻採樣
6. 離散餘弦轉換
7. 得到 CQCC 特徵

### 3. i-vector 語音特徵

i-vector 是基於聯合因子分析 Joint Factor Analysis 的方法，常用在語者辨識系統中。

i-vector 的特點包含：

- 通常會先擷取 MFCC 特徵
- 需要非註冊語者資料建立通用背景模型 UBM
- 可以把語音轉成固定長度的向量
- 例如固定成 400 維的語音特徵向量



## 八、Total Variability

投影片中提到語音的 Supervector 可以表示成：

```text
M = m + T × w
```

其中：

- `M`：語者 supervector
- `m`：UBM 的 supervector
- `T`：Total Variability Matrix
- `w`：語者 supervector 對應的 i-vector

我的理解是，Total Variability 的概念是把語音中的變異性用一個低維度向量表示。因為原始語音特徵可能很複雜，所以系統會透過矩陣轉換，把重要資訊壓縮成比較容易處理的 i-vector。



## 九、系統架構

投影片中有展示整體系統架構，主要可以分成兩個部分。

### 1. 偵測攻擊特徵

第一部分是針對欺騙攻擊的語音特徵進行擷取。這部分使用 CQCC 特徵，接著透過分類器判斷語音是否可能是偽造語音。

### 2. 語者辨識特徵

第二部分是針對語者身分進行辨識。這部分會使用 MFCC、i-vector 等特徵，再輸入到分類器中進行判斷。

投影片中的分類器包含：

- SVM
- Random Forest
- DNN
- Ensemble model
- Multi-model DNN



## 十、整體學習 Ensemble Learning

整體學習的概念是把多個不同的分類器整合在一起，最後再根據這些分類器的結果做判斷。

投影片中提到常見方式有：

- 多數決 Majority Voting
- 加權投票 Weighted Voting
- 一致決 Unanimity Voting

其中 unanimity voting 是比較嚴格的方法，必須所有分類器都有相同判斷，才會讓語音通過系統。這樣可以提高安全性，但也可能增加拒絕正常使用者的機率。



## 十一、分數正規化

分數正規化主要是把模型輸出的分數轉換到比較一致的範圍，讓不同模型或不同分數可以比較。

老師有提到，正規化方法可以同時提高目標語者的接受率與冒充者的拒絕率。這是因為目標語者和冒充者的分數分布可能會有部分重疊，透過正規化可以讓兩者更容易被區分。



## 十二、條件式重試機制

條件式重試機制的目的是降低正常使用者被錯誤拒絕的情況，也就是降低 false rejection。

如果系統判斷分數落在比較不確定的區域，就不要立刻拒絕使用者，而是讓使用者再嘗試一次或兩次。

這樣可以增加合法使用者通過的機會。但是如果重試太多次，也可能增加攻擊者嘗試成功的機率，所以重試次數不能無限制增加。



## 十三、訓練資料與模型設定

投影片中提到訓練資料使用 ASVspoof2019。這個資料集包含 bonafide 語音以及 spoofing attack 語音，可以用來訓練語音反欺騙系統。

訓練資料大致包含：

- 目標語者語音
- 冒充者語音
- 欺騙攻擊語音
- 不同語音庫資料

模型部分使用 **Single-DNN** 架構，門檻值採用決策方式。



## 十四、欺騙攻擊偵測系統參數

投影片中提到一些模型參數設定，例如：

- 輸入層大小為 60 × 150 = 9000
- 其中 60 為 CQCC 維度
- 150 為一秒的 frame size
- 輸出結果為預測真實語音 Real 的機率
- 神經元數量可設定為 9000、3216、1 等結構
- 使用 Adam optimizer
- 學習率約為 0.001
- Loss function 使用 Binary Cross Entropy
- Batch size 為 64

從這些設定可以看出，這個系統是把語音特徵整理成固定大小後，再交給神經網路進行二分類判斷。



## 十五、降維實驗結果

投影片中有一張表格是降維實驗，主要比較不同降維方式對 Real 通過率與 Spoofing 通過率的影響。

從表格可以看到：

- 原始維度 9000 時，Real 通過率約 96.6%，Spoofing 通過率約 14.3%
- 使用 LDA 降到 1 維時，Real 通過率下降到約 87.2%，Spoofing 通過率約 16.6%
- 使用 PCA 降到 4500、900、450、90 維時，Real 通過率大約在 87% 到 92% 之間，Spoofing 通過率大約在 15% 到 19% 之間

我的理解是，降維可以減少資料量與模型負擔，但如果降太多維，可能會造成特徵資訊流失，導致辨識效果變差。



## 十六、個人心得

這次演講讓我對語者辨識和語音安全有更清楚的認識。以前我對語音辨識的理解，大多是把語音轉成文字，或是像手機語音助理那樣聽懂使用者在說什麼。但這次演講讓我知道，語音技術不只可以辨識內容，也可以辨識「是誰在說話」。

我覺得語者辨識很實用，因為每個人的聲音都有自己的特色，所以它可以被拿來做身分驗證。不過這次演講也讓我發現，語音驗證並不是絕對安全的。像是錄音回放、語音合成、語音轉換這些攻擊方式，都可能讓系統誤判。尤其現在 AI 生成聲音越來越自然，如果系統沒有反欺騙機制，就可能被假語音騙過。

我印象比較深的是 CQCC 和 i-vector 這兩個特徵。CQCC 比較偏向從頻譜角度分析語音真假，而 i-vector 則是把語音轉換成固定長度的語者特徵向量。這讓我覺得語音辨識不是單純把聲音丟進模型而已，前面的特徵擷取其實非常重要。

整體來說，這次演講讓我了解到語者辨識是一個結合語音處理、機器學習、深度學習和資安防護的技術。未來如果語音登入、智慧裝置或金融驗證越來越普及，語音反欺騙技術也會變得更重要。

## 十八、結論

本次演講主要介紹語者辨識系統，以及如何面對冒充者與欺騙攻擊。語者辨識可以透過聲音特徵判斷使用者身分，但也可能受到錄音回放、語音合成、語音轉換等攻擊影響。因此，系統需要加入反欺騙偵測與防禦機制。

在技術上，CQCC、i-vector、Total Variability 等方法可以用來擷取語音特徵，再搭配 DNN、SVM、Random Forest 或 Ensemble Learning 進行分類與判斷。除了模型準確率之外，分數正規化和條件式重試機制也能改善系統的實用性。

我認為語者辨識未來會在身份驗證與資安應用中扮演重要角色，但前提是必須同時處理安全性、準確率與使用者體驗。如果能有效偵測 spoofing attack，語音辨識系統就能更安全地應用在真實生活中。
